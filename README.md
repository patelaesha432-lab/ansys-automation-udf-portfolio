# ANSYS Fluent Automation & Custom C UDF Suite

Automated CFD workflows using custom **C User Defined Functions (UDFs)** for Fluent solvers.

## Featured Code Modules
* **Parabolic Velocity Profile (`c-udfs/parabolic_inlet_velocity.c`):** Implements a fully developed 2D parabolic velocity profile at boundary inlets using the `DEFINE_PROFILE` macro. Designed for parallel and serial execution.

## Tech Stack
* **Language:** C
* **Target Software:** ANSYS Fluent
